# 🤖 Gemini Multimodal Content Generator

An AI-powered web application built using Python, Streamlit, and Google Gemini API. It allows users to generate text, create detailed image prompts, and convert text into audio.

## 🚀 Features

- **Text Generation:** Generate AI-powered text using Google Gemini.
- **Image Prompt Generator:** Create detailed prompts for AI image-generation platforms.
- **Audio Generation:** Convert text into speech using Google Text-to-Speech (gTTS).
- **Multi-Modal Generation:** Generate text, image prompts, and audio from a single input.

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
- gTTS (Google Text-to-Speech)

## ⚙️ Installation and Setup

1. Clone this repository:

   `git clone https://github.com/bhumikapatel5155-creator/Gemini-Multimodal-Generator.git`

2. Navigate to the project directory:

   `cd Gemini-Multimodal-Generator`

3. Install the required dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run gemini_multimodal_app.py`

5. Enter your Gemini API key in the application sidebar.

## 🔑 API Key Setup

Get your API key from [Google AI Studio](https://aistudio.google.com/apikey).

Keep your API key private. Never upload it to GitHub.
